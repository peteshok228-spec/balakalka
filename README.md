# Балакалка — голосовой ввод с умной расстановкой знаков

Нажимаете **Ctrl+Shift+Пробел**, говорите, нажимаете ещё раз — и в окно, где стоит курсор
(Word, Telegram, браузер, что угодно), вставляется готовый текст: с запятыми, точками,
заглавными буквами и **исправленными по смыслу словами**.

## Как это устроено и почему так точно

Работа идёт в два этапа, как у Wispr Flow и Superwhisper:

1. **Распознавание речи — Whisper.** Переводит звук в буквы. Хорошо слышит, но не
   понимает смысла: путает «компанию» и «кампанию», склеивает и разбивает слова,
   теряет запятые, коверкает имена и термины.
2. **Редактура — Claude.** Получает весь сырой текст целиком и делает то, что делает
   человек при чтении: расставляет знаки препинания, делит текст на предложения и абзацы,
   заменяет неверно услышанные слова на подходящие по смыслу, убирает «э-э», «ну»,
   «как бы», а если вы по ходу поправились («во вторник, нет, в среду»), оставляет
   итоговый вариант. Пересказывать или «улучшать» ваш стиль ему запрещено.

Поэтому результат почти как у меня в чате: я тоже понимаю речь по контексту, а не
только по звукам.

Если Claude недоступен (нет интернета, кончились деньги на балансе), вставляется
сырой текст из Whisper — диктовка не пропадёт. Кроме того, каждая диктовка
сохраняется в `history.txt`.

## Установка (Windows)

1. Установите **Python 3.10 или новее** с [python.org](https://www.python.org/downloads/).
   В установщике поставьте галочку **«Add Python to PATH»**.
2. Скачайте эту папку и дважды щёлкните `run_windows.bat`. При первом запуске
   программа сама поставит всё нужное (несколько минут).
3. Рядом с программой появится файл `config.json`. Закройте окно программы,
   откройте `config.json` Блокнотом и впишите ключи (см. ниже).
4. Снова запустите `run_windows.bat`. Окно с текстом не закрывайте — в нём видно,
   что программа услышала и что вставила.

**macOS / Linux:** запускайте `./run_mac_linux.sh`. На macOS программе нужно разрешение
в «Настройки → Конфиденциальность → Универсальный доступ» и «Мониторинг ввода» (для
Терминала), на Linux — пакеты `portaudio19-dev`, `xclip` и `python3-tk`.

## Ключи

**Claude (обязательно для умной редактуры).** Создайте ключ на
[console.anthropic.com](https://console.anthropic.com/) → API Keys, пополните баланс
(хватит и $5 на месяцы диктовки) и впишите в `config.json`:

```json
"anthropic_api_key": "sk-ant-...",
```

**Распознавание речи** — выберите один вариант:

| Вариант | Настройки в `config.json` | Плюсы и минусы |
|---|---|---|
| **Локально** (по умолчанию) | `"stt_backend": "local"` | Бесплатно, звук не уходит в интернет. При первом запуске скачивается модель (~1,6 ГБ). На слабом компьютере без видеокарты NVIDIA может думать 5–15 секунд. Тогда поставьте `"local_model": "small"` — быстрее, но точность ниже. |
| **Groq** | `"stt_backend": "openai"`, `"openai_base_url": "https://api.groq.com/openai/v1"`, `"openai_model": "whisper-large-v3-turbo"`, `"openai_api_key": "gsk_..."` | Очень быстро (меньше секунды), есть бесплатный лимит. Ключ: [console.groq.com](https://console.groq.com/keys). |
| **OpenAI** | `"stt_backend": "openai"`, `"openai_model": "gpt-4o-transcribe"`, `"openai_api_key": "sk-..."` | Лучшее качество распознавания русского, платно, но недорого. |

На слабом ноутбуке советую Groq: быстро и почти бесплатно.

## Настройки, которые стоит знать

Всё лежит в `config.json`. После изменений перезапустите программу.

- `"hotkey"` — комбинация клавиш. Примеры: `"<ctrl>+<shift>+<space>"`,
  `"<ctrl>+<alt>+d"`, `"<f9>"`.
- `"cancel_hotkey"` — отменить запись без вставки (по умолчанию Ctrl+Shift+Backspace).
- `"vocabulary"` — **самая полезная настройка.** Впишите имена, названия, термины,
  которые вы часто говорите. Это подсказка и Whisper, и Claude:
  ```json
  "vocabulary": ["Балакалка", "Kubernetes", "Анна Сергеевна", "ООО «Ромашка»"]
  ```
- `"extra_instructions"` — пожелания к оформлению своими словами, например
  `"Всегда пиши букву ё. Обращение «вы» с маленькой буквы."`
- `"remove_fillers"` — убирать слова-паразиты (`true`/`false`).
- `"claude_model"` — модель для редактуры. По умолчанию `claude-opus-5-5`, самая умная.
  Если хочется быстрее и в десятки раз дешевле, попробуйте `claude-haiku-5-5`:
  с пунктуацией она справляется хорошо, но в сложных созвучиях иногда уступает.
- `"claude_effort"` — `low` (быстро, по умолчанию) / `medium` / `high` (внимательнее,
  но дольше).
- `"polish": false` — выключить Claude и вставлять сырой текст Whisper.
- `"auto_paste": false` — не вставлять автоматически, а только положить текст в буфер
  обмена (дальше Ctrl+V вручную).

## Сколько это стоит

Цены ориентировочные, на минуту диктовки:

- Claude Opus 5.5 — около 1–2 центов; Claude Haiku 5.5 — доли цента.
- Whisper локально — бесплатно; Groq — почти бесплатно; OpenAI — меньше цента.

Даже при часе диктовки в день выходит несколько долларов в месяц.

## Похожие готовые приложения (на что ориентировался)

| Приложение | Что умеет | Чем отличается |
|---|---|---|
| **Wispr Flow** | Та же схема: клавиша → речь → нейросеть чистит текст | Подписка ~$12–15 в месяц, закрытый код |
| **Superwhisper** (macOS) | Whisper + «режимы» с LLM-обработкой | Только Mac, платный |
| **Aqua Voice** | Диктовка с умным редактированием | Платный |
| **VoiceInk** (macOS) | Открытый код, локальный Whisper + ИИ-доводка | Только Mac |
| **OpenWhispr**, **whisper-writer** | Открытый код, Whisper по горячей клавише | Без редактуры по смыслу (или с базовой) |
| **Win+H** в Windows, диктовка в macOS | Встроено в систему | Знаки и слова по смыслу почти не исправляет |

Балакалка — минимальная версия той же идеи, которую можно настроить под себя:
свои слова, свой стиль, своя модель.

## Если что-то не работает

- **Ничего не происходит по нажатию клавиш** — комбинацию может перехватывать другая
  программа, задайте другую в `"hotkey"`. На macOS проверьте разрешения.
- **Текст не вставился** — он уже в буфере обмена и в `history.txt`: нажмите Ctrl+V.
  Некоторые программы, запущенные от администратора, не принимают вставку от обычных
  программ; тогда запустите Балакалку тоже от администратора.
- **«Нет доступа к микрофону»** — Windows: Параметры → Конфиденциальность →
  Микрофон → разрешить классическим приложениям.
- **Медленно** — см. таблицу выше: Groq вместо локального Whisper, `claude-haiku-5-5`
  вместо Opus.

## Устройство кода

```
balakalka/
  app.py         — горячие клавиши, запись, порядок обработки
  audio.py       — запись с микрофона (16 кГц, моно)
  transcribe.py  — Whisper: локально или через API
  polish.py      — редактура через Claude (здесь же текст инструкции для модели)
  output.py      — вставка в активное окно, звуки, история
  overlay.py     — плашка «Запись / Обработка» внизу экрана
  config.py      — настройки по умолчанию
```

Инструкцию для Claude (что исправлять, чего не трогать) можно править прямо в
`balakalka/polish.py` → `SYSTEM_PROMPT`.
